# Red Definitiva

Red Definitiva es una red local/global para recuperar perros y gatos perdidos y reunirlos con sus familias.

## Objetivo

Cuando un animal se pierde, la plataforma convierte una situación caótica en un operativo coordinado:

- registro único de animales perdidos y encontrados;
- mapa operativo con área máxima y sectores;
- equipo de búsqueda geolocalizado;
- protocolo guiado;
- pistas y avistamientos diferenciados;
- modo de contención cuando un miembro localiza al animal;
- puntos de apoyo cercanos;
- difusión;
- futuras capacidades de IA para capturar casos públicos y detectar coincidencias.

## Principio central

> Si se pierde un animal, no tenés que buscar en cien lugares. Hay un solo lugar.

## Estado

Proyecto en etapa de especificación / pre-MVP.

## Rol del fundador

El fundador actúa como Product Owner / Director de concepto: valida el problema, el comportamiento esperado y la experiencia real de búsqueda. El desarrollo debe minimizar la necesidad de intervención técnica del fundador.

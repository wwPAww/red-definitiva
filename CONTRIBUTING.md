# Contribuir

Red Definitiva se plantea como un proyecto abierto y modular.

## Antes de programar

1. Leer `docs/producto.md`.
2. Leer `docs/protocolo.md`.
3. Revisar `docs/roadmap.md`.
4. Elegir una tarea concreta del backlog.

## Principios

- Mobile-first.
- Pocos pasos durante una emergencia.
- Privacidad por defecto.
- Ubicación compartida solo durante un operativo activo.
- Una pista no es un hecho confirmado.
- La detección directa de un miembro del operativo tiene tratamiento distinto.
- No perseguir animales asustados.
- No inventar integraciones ni capacidades externas.

## Tipos de contribución

Código, UX, mapas, geolocalización, protocolo, investigación, accesibilidad, pruebas, documentación, datos y difusión.
